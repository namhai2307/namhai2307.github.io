Autonomous Sumo Robot

Description

An autonomous sumo robot designed to compete in robotic sumo wrestling competitions. The robot uses multiple sensors to detect opponents and avoid falling off the ring.

Hardware Components:

  • ESP32 (TTGO): Main microcontroller for processing sensor data and controlling motors.
  • 3 Ultrasonic Sensors: Detect and locate opponents on the sumo ring.
  • Infrared Sensors: Positioned at the bottom to detect the edge of the sumo ring and prevent the robot from falling off.
  • LN298 Motor Driver: Controls the DC motors for movement and maneuverability.
  • Lithium Batteries: Power supply for all components.

Software Architecture:

Detail code on github: https://github.com/namhai2307/Sumo-Robot

Programmed in C++ using the Arduino framework for ESP32. The software implements a priority-based control system with three autonomous behavioral states:

Behavioral States

  • SEARCH State: Robot performs randomized turning movements (left/right) every 500-900ms while continuously scanning with ultrasonic sensors to locate opponents.
  • ATTACK State: Activated when ultrasonic sensor detects an opponent within 40cm. Robot charges forward or turns toward the opponent depending on sensor position, with response time under 45ms.
  • RETREAT State: Highest priority state. When IR sensors detect the black arena edge, robot executes a 3-phase recovery: backing away from edge (300ms), turning toward arena center (400ms), and resuming search.

Control Logic

  • SEARCH → ATTACK: Opponent detected within 40cm
  • ATTACK → SEARCH: Opponent moves out of range (>40cm)
  • Any State → RETREAT: IR sensor detects arena edge (safety override)
  • RETREAT → SEARCH: Recovery sequence complete
